# IP 출처 및 출시 전 확인

2026-09-26 기준 코드 감사. 게임 화면의 스타포스·큐브·윗/아랫잠재·에디셔널 표시를 나이테 성장·새김석·주/심층 각인으로 변경했다. 장비 각인 등급 표시는 이슬→새순→가지→거목→세계수로 변경했으며, 기존 저장 데이터의 내부 등급 값은 유지한다. 강화 화면의 장비 별 표시는 나이테 단계로, 각인 세 칸은 두 뿌리와 잎맥으로 표시한다. 확률과 재화 수치는 저장 호환성을 위해 유지했다.

코드 검색만으로 그래픽 저작권을 확정할 수 없다. 저장소에는 직업 초상화, 몬스터, 배경, 장비, 월드보스 WebP 이미지가 있다. 일부 이미지가 AI 생성·외부 도구 제작·무료 에셋인지 추적 가능한 원본 파일, 생성 기록, 라이선스가 현재 저장소에 없다. 상업 이용 권한의 근거를 파일별로 수집하고, 출처를 입증하지 못하는 이미지는 출시 전에 교체한다. 이 점검은 메이플 원본 이미지 전체와 픽셀 단위 대조를 수행한 법률 감정이 아니다.

`release/asset-ledger.json`은 `python scripts/asset-ledger.py`로 만든 이미지 51개의 SHA-256, 크기, 저장소 최초 반입 커밋을 기록한다. 이 중 코드로 재생성할 수 있는 앱 아이콘 1개만 제작 근거가 있다. 나머지 50개는 반입 커밋만 확인되며 원저작물의 제작 주체·상업 이용 허락은 확인되지 않았다. 이 기록의 `commercial_rights_verified: false` 항목을 권리 증빙 또는 출처가 분명한 새 원본으로 해결하기 전에는 해당 이미지를 포함한 공개 배포를 승인하지 않는다. 커밋 작성자가 파일을 추가했다는 사실은 저작권 소유의 증거가 아니다.

Android 앱 패키징은 권리 근거가 있는 아이콘만 `www/assets`에 복사하고, 게임의 코드로 그린 캐릭터·몬스터·배경 대체 그림을 사용한다. 원본 웹 배포는 여전히 해당 WebP를 참조하므로 웹 공개본의 권리 문제는 별도로 해결해야 한다. `npm run check:release-art`는 전체 저장소 아트의 권리 근거가 확인될 때까지 의도적으로 실패한다. 기존 이미지의 권리 근거가 제공되면 파일별 증빙을 검토하고 해시와 출처를 갱신한다.

새 Android 아이콘은 `scripts/make-icon.py`의 도형 코드로 제작했다. `assets/app-icon-512.png` 및 Android 런처/스플래시 이미지를 같은 소스로 재생성할 수 있다.

상표명 `새싹 원정대`의 등록 가능성은 아직 확인되지 않았다. 기존 시작 화면의 `ALPI GAMES` 표기는 제거했다. KIPRIS에서 게임 소프트웨어 관련 상품류를 포함해 동일·유사 표장을 최종 검색하고, 출시 명칭을 확정한다. 필요하다면 전문 변리사/변호사의 최종 검토를 받는다.
