현재 개발 빌드의 진행도는 기기 내부 저장소에 저장됩니다. 이용자가 직접 내보내기를 선택하면 세이브 파일이 기기의 공유 기능을 통해 선택한 앱이나 저장 위치로 전달됩니다. 가져온 파일은 이용자가 직접 선택한 경우에만 게임 진행도에 반영됩니다.

Android 디버그 빌드는 Google의 AdMob 데모 광고를 시험할 수 있습니다. 광고 SDK와 동의 SDK가 처리하는 기기 식별자 및 진단 자료, 수집·공유 여부, 보관 기간은 실제 프로덕션 광고 설정과 SDK 버전 확인 후 명시해야 합니다. 현재 공개 출시용 광고·결제·분석 서비스는 활성화하지 않았습니다.

계정·클라우드 세이브, 실제 광고, 결제, 분석 또는 오류 보고를 추가할 경우 목적, 항목, 제공처, 처리 위치, 보관·삭제 방법, 이용자 선택권과 연락처를 실제 구현에 맞게 갱신해야 합니다. 이 문서는 법적 게시물이 아니며, 운영자 정보와 실제 배포 바이너리의 Data Safety 답변을 맞춘 뒤 공개 URL에 게시해야 합니다.
